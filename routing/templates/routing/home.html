Endpoints

POST /api/v1/route/body {"start": "New York, NY", "finish": "Chicago, IL"} → route, fuel stops, total cost
GET /api/v1/route/?start=&finish=same response, for browsers
GET /api/v1/route/map/?start=&finish=interactive map
GET /api/v1/health/health check
API documentation (Swagger)try every endpoint interactively

Accepted locations: City, ST, City, State or lat,lon, inside the contiguous USA. One routing-API call per new trip; repeats are served from cache.
